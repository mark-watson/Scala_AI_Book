# OpenAI LLM Client — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

A REST client for the OpenAI Chat Completions API using `requests-scala` and `ujson` in Scala. Demonstrates basic prompt completions using `gpt-4o-mini`.

## Setup

Set your OpenAI API key:

```bash
export OPENAI_API_KEY="your-api-key-here"
```

## Run

    scala-cli run .
