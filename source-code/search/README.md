# Search Algorithms — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

Demonstrates graph search (DFS & BFS), maze solving, and game-tree search (Tic-Tac-Toe with minimax).

## Run

    scala-cli run .
