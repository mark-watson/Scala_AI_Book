## Projects

Each project is a standalone [scala-cli](https://scala-cli.virtuslab.org/) project. Run any example with:

    cd <project-directory>
    scala-cli run .

| Directory | Description |
|---|---|
| `gemini-client` | Google Gemini REST API client (generate, search, chat, tools) |
| `openai-client` | OpenAI chat completions and embeddings client |
| `ollama-client` | Ollama local LLM REST API client |
| `search` | Graph, maze, and game-tree search algorithms |
| `neural-networks` | Backpropagation neural networks (from scratch) |
| `genetic-algorithms` | Genetic algorithm optimization framework |
| `anomaly-detection` | Anomaly detection using statistical methods |
| `nlp` | Natural language processing: tokenizer and POS tagger |
| `semantic-web` | Semantic Web / SPARQL with Apache Jena |
| `kgn` | Knowledge Graph Navigator — queries DBPedia via SPARQL |
