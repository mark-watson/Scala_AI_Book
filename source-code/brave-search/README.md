# Brave Web Search — Scala AI Book

A small Brave Search API client that returns URL, title, and snippet
triples for agents and RAG pipelines, ported from `brave_search` in
the Loving Common Lisp repo.

## Run (needs `BRAVE_SEARCH_API_KEY`)

    scala-cli run . --main-class bravesearch.braveDemo

## Test (offline)

    scala-cli run . --main-class bravesearch.braveTest
