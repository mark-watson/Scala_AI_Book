# Gemini LLM Client — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

A REST client for the Google Gemini API using `requests-scala` and `ujson` in Scala. Demonstrates basic prompt completion and search grounding (Google Search tools) using `gemini-2.5-flash`.

## Setup

Set your Google AI API key:

```bash
export GOOGLE_API_KEY="your-api-key-here"
```

## Run

    scala-cli run .
