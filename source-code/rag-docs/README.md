# Agentic RAG with Local Docs — Scala AI Book

Chunking, TF-IDF plus BM25 retrieval, query rewrite, and answer
prompts, after `RAG`, `docs-qa`, and `autocontext` in the Loving
Common Lisp repo. Live answers use local Ollama when it runs.

## Run

    scala-cli run . --main-class ragdocs.ragDemo

## Test (offline, no model needed)

    scala-cli run . --main-class ragdocs.ragTest
