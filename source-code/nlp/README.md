# Natural Language Processing (NLP) — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

Text tokenization, heuristic Part-of-Speech (POS) tagging, and Rule-based Named Entity Recognition (NER) for human and place names, implemented in pure Scala.

## Run

    scala-cli run .
