# Genetic Algorithms — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

Genetic algorithm framework with roulette-wheel selection, crossover, mutation, and duplicate removal. Includes an optimization example that finds the maximum of `sin(x) * sin(0.4x) * sin(3x)`.

## Run

    scala-cli run .
