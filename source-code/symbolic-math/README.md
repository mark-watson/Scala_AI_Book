# Symbolic Math — Scala AI Book

Polynomial differentiation and integration with sealed case classes
and pattern matching, ported from `symbolic-math` in the Loving
Common Lisp repo. Pure Scala, no deps.

## Run

    scala-cli run . --main-class symbolicmath.symbolicMathDemo

## Test

    scala-cli run . --main-class symbolicmath.symbolicMathTest
