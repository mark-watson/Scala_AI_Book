# Knowledge Graph Navigator (KGN) — Scala AI Book

Example for Mark Watson's book "Practical Artificial Intelligence With Scala"

A console application that performs Named Entity Recognition (NER), maps extracted entities to DBpedia URIs, and uses SPARQL queries to query DBpedia for detailed descriptions and semantic relationships between entities.

## Run

    scala-cli run .
